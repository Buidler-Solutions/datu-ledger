Sign in to a site (SignetAuth)

        

          Challenge-response login: the site issues a one-time challenge, your
          Signet signs it, the site verifies against your public key. No
          password reaches the site, and the assertion is useless if replayed
          (datu-auth-v1).
        

        
        
        
        
        
        

          
You are signing in as this identity to this site

          

          

            
            
          

        

        
        
        

          The assertion never becomes a ledger entry and can never be reused as one.

Create identity (set your passphrase)

        

          You choose the passphrase - it locks your keys with Argon2id. It is never stored or
          sent anywhere, and it cannot be recovered: if you lose it, the keys and the sealed
          data addressed to them are lost.
        

        
        
        
        
        


        
Signet connection

        

          
looking for a local Signet service…

          

            
          

          

            

              No Signet service answered on this machine. The panel talks to a local
              Signet process (the DATU Wallet desktop app, or
              datu signet serve). Keys live there, never in this extension.

Signets on this device

        

          One Signet per person, several identities inside for context
          (alice-home, alice-business). A Signet is one
          datu wallet serve process: its own directory, passphrases and token.
          The panel never holds keys - it asks the bridge to sign and decrypt.
        

        
        

          
          
        

        
        
        

          Advanced: pair with a token by hand (only if auto-detection cannot reach the Signet)
          
          

            
            
          

          

            The extension can self-pair with any Signature service it can reach, so this is
            only for unusual setups (remote bridge, custom port, locked-down browser).
          

        

        

          
        

        


        
Device passkey unlock

        

          Replace typing the passphrase with a device passkey (Touch ID, Windows
          Hello, PIN). The passphrase is wrapped under a key only your passkey
          can derive, and is unwrapped into panel memory for this session after
          a biometric gesture. Losing the passkey changes nothing: type the
          passphrase as before.
        

        
        
        

          
          
          
        

        
Pick an identity in the header, type its passphrase above, then protect it. After that, Unlock with passkey replaces typing.


        
Backup & move devices

        

          Exports the selected identity as a file encrypted with a separate backup
          passphrase. Import it on another device - the restored identity unlocks with
          that backup passphrase.
