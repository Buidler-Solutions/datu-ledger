# DATU v0.2.1-rc1

Release candidate for the production-readiness hardening. No protocol or
data-format changes: existing nodes, stores, policies, and bundles work
unchanged.

This is the first release produced by the signed, reproducible pipeline.
Every artifact below is covered by `SHA256SUMS`, the sums are signed with
Sigstore (keyless), and the release ships a full SPDX 2.3 SBOM. Two
RUSTSEC advisories were fixed since v0.2.0 (bundled SQLite via
`rusqlite`, and `libz-sys`).

## What changed since v0.2.0

### Security and supply chain

- Bridge (Signet) hardening: adversarial tests pin the passphrase
  lockout, grant boundaries, provider-route rate limiting, hostile
  token/origin refusal, and oversized-body handling; the limiter is now
  per instance. Review note: `deploy/security/bridge-hardening.md`.
- Wire and HTTP parsers fuzzed under seeded hostile input (frame
  decoders, live listener abuse, request-reader garbage, cursor and
  query clamping), all no-panic with liveness checks.
- Party-signature canonical vector pinned and verified cross-language
  (Rust, Node, pure Python), alongside the existing entry, auth, and
  checkpoint vectors.
- SPDX 2.3 SBOM covering cargo and npm dependencies, shipped with the
  release and validated in CI.
- Advisories fixed: `rusqlite` 0.41 / bundled SQLite 3.54.1
  (RUSTSEC-2026-0459), `libz-sys` 1.1.33 (RUSTSEC-2026-0544).

### Reliability and operations

- Key-custody drill (`deploy/drills/key-rotation.sh`): history survives
  a host and key move, a revoked key is refused by the validator with
  the reason visible in sync output, and the replacement key is
  admitted. Runbook: `deploy/operations/key-custody.md`.
- Policy denial reasons are now reported on every sync, bundle-import
  and delta-merge path, so refusals say why (revoked, gated, read-only).
- Fork drill proves both contradiction verdicts (bundle history
  mismatch and same-height witness fork) plus an honest control.
- Soak at 10k entries reports publish rate, disk cost, and sync lag
  (a fresh observer catches up 10,001 entries in about 3 seconds).
- Operations runbooks: disk growth and retention, incident response,
  topology, wire-privacy decision, recovery flows, sealing and GDPR
  map for counsel.

### CI and release engineering

- Seven-job matrix on every push: Linux and macOS tests, projection
  dialects (SQLite, PostgreSQL, MariaDB), rustdoc with warnings as
  errors, bit-reproducible release builds proven from two checkout
  paths, dependency advisories, and the full drill suite.
- Release artifacts are reproducible (remapped paths, pinned epoch,
  deterministic archives) and signed keyless with Sigstore; verification
  steps in `deploy/operations/release-signing.md`.

## Verify this release

```bash
grep "datu-v0.2.1-rc1-x86_64-apple-darwin.tar.gz" SHA256SUMS | shasum -a 256 --check
cosign verify-blob --signature SHA256SUMS.sig --certificate SHA256SUMS.pem \
  --certificate-identity-regexp "^https://github.com/greenarmor/datu-ledger/" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" SHA256SUMS
```

Rebuild from source with the same recipe (`deploy/checks/reproducible.sh`)
and the binary hash inside the archive should match byte for byte.
