# Code of conduct

## Our pledge

We want participation in this project to be harassment-free for everyone,
regardless of age, body size, disability, ethnicity, sex characteristics,
gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.

## Expected behaviour

- Be direct about code and kind about people.
- Assume good faith, ask before assuming malice.
- Accept that "no" with a reason is a complete answer.
- Respect privacy: no personal data from real deployments in issues or PRs.

## Unacceptable behaviour

Harassment, discrimination, threats, doxxing, publishing private information
without consent, and sustained disruption of discussion.

## Scope and enforcement

This applies in repository spaces and wherever someone represents the
project. Report concerns to the maintainers listed in `MAINTAINERS.md`;
reports are handled privately. Consequences range from a warning to a
permanent ban, decided by the maintainers and recorded.

This document is adapted from the Contributor Covenant, version 2.1.
